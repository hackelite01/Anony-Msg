QUICK START
===========
cd bot
cp .env.example .env           # Edit this with your credentials
pip install -r requirements.txt
python bot.py                  # Runs on http://0.0.0.0:8000

IMPORTANT
=========
✅ All production code is in bot/
❌ Never edit legacy/ (it's archived)
⚙️  Always configure bot/.env before running
🌐 Use bot/render.yaml for Render deployment
📝 Admin panel: type /admin in Telegram

IGNORE
======
- legacy/ folder (old versions, reference only)
- .env file in root (use bot/.env instead)
